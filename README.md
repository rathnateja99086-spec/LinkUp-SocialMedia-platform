# LinkUp

A modern social media web application built with HTML, Tailwind CSS, JavaScript, Firebase Authentication, and Cloud Firestore.

## Features

- User Registration
- User Login
- Google Authentication
- Create Posts
- Like & Unlike Posts
- Comment System
- Follow Users
- User Search
- User Profiles
- Responsive Design

## Tech Stack

- HTML
- Tailwind CSS
- JavaScript (ES6)
- Firebase Authentication
- Cloud Firestore
